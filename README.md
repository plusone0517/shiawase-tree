# しあわせの木

こころに、ひとこと。毎日に、小さなやさしさを。

## 機能

- 36のオリジナルメッセージ、テーマ別の本棚、お気に入り
- 自分のことばの追加・編集・削除
- 日替わりの小さな行動と、1日1回の達成記録
- 合計3日・7日・14日で木が成長。休んでも枯れません
- ひとことメモ、日々のふりかえり
- JSONバックアップの書き出し・検証付き取り込み
- スマートフォン対応、日本語UI

## 保存

記録は使用中のブラウザーのIndexedDBに保存します。アカウント登録やサーバー送信、端末間の自動同期はありません。ブラウザーデータを削除する前にバックアップしてください。

初期のことばは編集済みオリジナルメッセージです。ライブAI生成は使用していません。

## 公開

GitHub Pages: main ブランチのルートを公開します。index.html は画像・CSS・JavaScriptを含む実行可能な単一ファイルです。.nojekyll を同梱しています。

## ソース

source.zip にTypeScript/Reactソース、CSS、画像、依存関係のロックファイル、ビルドスクリプトを同梱しています。展開後に pnpm install --frozen-lockfile、node scripts/build-portable.mjs index.html で静的アプリを生成できます。

## 検証

TypeScript型チェック・本番ビルド成功。ブラウザーでお気に入り、自作メッセージの追加・編集、再読み込み後の保存、同日ダブルクリックの重複防止、バックアップ読み込み、3日達成時の成長、390px幅のナビゲーションとダイアログを確認。
日付検証、成長段階の境界、バックアップの往復・重複統合・不正データ拒否も確認しています。

WebMCP の read_garden_summary は機能検出付きの読み取り専用補助機能です。検証ブラウザーで対応APIを利用できない場合も、通常UIは動作します。
